# SaveGeniusBot - ✨ O extrator mais completo do Telegram.

Cola o link e recebe em segundos: vídeo, foto, story ou texto - sem marca de água, sem apps, sem complicações.

E o melhor? A IA reescreve a legenda para ti, com título, descrição e hashtags novas, prontas a publicar.

📎 Instagram • TikTok • YouTube • Pinterest

Bot do Telegram que descarrega videos + devolve Titulo + Descricao + Hashtags + Nova Descricao com IA.

## Como usar
Manda um link do Instagram / TikTok / YouTube / Pinterest

- Gerar Nova Descricao com IA
